CURRENT PUBLIC ASSEMBLY STATUS SENSITIVITY -- AUDIT ONLY

Scope and provenance
The exact426 retained assembly versions were reconciled against NCBI Datasets
API reports retrieved2026-09-30 UTC. Nine batch snapshots supplied422 reports;
an all_assemblies historical-version query resolved the remaining four. There
are401 current,22 suppressed and3 previous versions, with no unresolved records.
The model script independently parses the raw JSON and exactly agrees with the
separately produced cohort_status_reconciled.csv. Current status is not asserted
to describe the records at their original collection date. Suppression reasons
are heterogeneous; not all are contamination. Previous versions are not
categorized as demonstrated quality failures.

Design
Two predeclared bounded exclusions are analyzed separately: remove22 currently
suppressed records (404 remain:106 positive and298 negative) and retain only
401 currently current records (106 positive and295 negative; also removes the
three older versions). Both preserve every surviving genome's original seed42
fold assignment and stored-genus label. Both retain70 stored genera. Four
classifiers and two size-only LR baselines use unchanged original parameters,
exact training-only purity and>=3-genus filters, and training-only scaling.
One CPU/BLAS thread is used; there is no retuning or inventory reranking.
The original2286-family vocabulary/clustering and prevalence criterion remain
defined on the full426-panel, so this is fixed-matrix sensitivity, not an end-to-end
reconstruction or an independently collected external validation cohort.

Interpretation
Family-content discrimination remains for the surviving records, but its
strength is model- and metric-dependent. The suppressed-exclusion mean-fold
AUC range is0.8084–0.8771; the current-only range is0.8059–0.8809. The LR
family-content mean-fold AUC remains above the assembly-length baseline,
while RF's mean-fold AUC is below that baseline in these two sensitivities.
Equal-genus pooled scores are lower than genome-pooled scores, and their
population weights change when records/genera are removed. The same-row
reference therefore helps distinguish different comparison questions.

These results qualify the primary panel's current assembly-status provenance.
They do not justify silently replacing the reported426-genome evaluation or
recalculating the frozen476-family resource. They are single-fixed-partition
sensitivity checks; no inferential p value, threshold optimization or extra
classifier search is performed. Status filtering does not resolve all taxonomic
uncertainty or the global definition of the family matrix.

Suggested compact manuscript wording
"As a sensitivity analysis using public assembly statuses retrieved on30
September2026, we retained the original fold assignments and repeated model
fitting after excluding22 currently suppressed assembly records. The remaining
404 genomes included106 nif-labeled positives; mean fold AUCs were0.808,
0.877,0.859 and0.877 for random forest, gradient boosting, logistic regression
and XGBoost, respectively. A separate401-current-assemblies analysis also
excluded three previous versions and yielded0.806,0.874,0.864 and0.881.
These fixed-family-matrix checks used training-only feature filtering and did
not alter the frozen candidate inventory. Current status may differ from status
at original collection, and suppression reasons were heterogeneous."
